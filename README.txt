YTA DISTRICT KASHMORE - DIGITAL SYSTEM
=========================================

This package is a working front-end prototype.

ADMIN PASSWORD
YTA-Kashmore-2026

IMPORTANT:
This version stores records in the browser's localStorage. It is suitable for testing/demo use.
For a real public registration system where many teachers submit data from different phones,
you need a secure server/database backend and proper authentication. The admin password should
then be stored server-side, not in browser JavaScript.

FILES
index.html - complete mobile-friendly registration + admin dashboard.

FEATURES
- Membership registration
- Automatic registration number
- Taluka selection
- Status checking
- Admin login
- Verify/reject records
- Search/filter
- CSV export
- Basic dashboard statistics
